# Lab 04: 스킬 템플릿 컴파일러 & 정적 린터 — `skill-compiler`

## 🎯 실습 목표
1. 사람이 직접 60개 마크다운을 편집하지 않고, 템플릿(`.tmpl`)과 공통 보안 모듈(`common.md`)을 결합하여 `SKILL.md`를 컴파일하는 생성기(`gen.sh`)를 작성한다.
2. 스킬의 글자 수 초과(250자), 필수 트리거 누락, 경로 오류를 0.1초 만에 무료로 잡아내는 정적 린터(`validate.sh`)를 구축한다.

---

## 📋 과제
1. `starter/gen.sh`를 완성하여 `src/`의 템플릿을 `out/`으로 컴파일하세요.
2. `starter/validate.sh`를 완성하여 결함 픽스처들을 100% 잡아내는지 테스트하세요.
