# Lab 03: 상태 머신 기반 워크플로 스킬 — `module-analyst`

## 🎯 실습 목표
1. 복잡한 분석 작업을 단일 프롬프트가 아닌 **3단계 게이트웨이 워크플로**로 구조화한다.
2. 분석 전 임의 코드 수정을 금지하는 **Iron Law**를 스킬에 강제한다.
3. 동일 가설 3회 실패 시 사람을 호출하는 **3-Strike 중단 탈출 조건**을 설계한다.

---

## 📋 과제
`worksheet.md`를 열고 5가지 질문에 답하며 스킬의 명세서를 작성하세요:
1. 성공 기준 정의
2. Iron Law 선언문 작성
3. 3단계(Phase 1 인벤토리 ➔ Phase 2 의존성 ➔ Phase 3 리포트) 산출물 정의
4. 3-Strike 중단 조건 명세
5. `AskUserQuestion` 사용자 호출 포맷 작성
